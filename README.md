# Описание  

Простой набор скриптов и преднастроект для sing-box на подобие проекта [xkeen](https://github.com/Skrill0/XKeen), а так же автоматическим парсингом подписок.  
Скрипт установит новейшую стабильною версию sing-box с официального репозитория, предварительно настроенную конфигурацию, а так же скрипты для интеграции с политиками Keenetic/Netcraze, автоматического обновления подписок и создаст задачи в cron. 

# Установка/Настройка  

> [!NOTE]  
> Перед установкой  
> На роутере уже должен быть установлен Entware с доступом по ssh и "Модули ядра подсистемы Netfilter". Как это сделать подробно описано в [Инструкции от сообщества по установке xkeen](https://github.com/Corvus-Malus/XKeen), принцип тот же.  
> Остальные необходимые пакеты доустановятся автоматически  

1. Интерактивная установка/обновление/удаление  

```sh 
curl -sSL https://raw.githubusercontent.com/aratash/singkeen/main/bin/singkeen.sh | sh 
``` 

2. Автоматическая установка  

```sh 
curl -sSL https://raw.githubusercontent.com/aratash/singkeen/main/bin/singkeen.sh | sh -s -- install 
``` 

3. Автоматическое обновление  

```sh 
curl -sSL https://raw.githubusercontent.com/aratash/singkeen/main/bin/singkeen.sh | sh -s -- update 
``` 

4. Автоматическое удаление  

```sh 
curl -sSL https://raw.githubusercontent.com/aratash/singkeen/main/bin/singkeen.sh | sh -s -- remove 
``` 

В ходе интерактивной установки скрипт предложит создать задачу в cron для автоматического обновления подписок и для обновления скриптов из репозитория. В ходе автоматической установки скрипт сам создаст задачу для авто обновления подписок раз в сутки в 4:00, а обновления скриптов будут отключены.  

## Авто обновление подписок  

Скрипт `singbox-subs-parser.py` берёт ссылки конфигураций и подписок из `/etc/sing-box/subs.txt`, парсит подписки и собирает конфигурацию. Он создаёт `balancer` (`type:selector`) и `auto` (`type:urltest`) балансировщики с добавляет в них все конфигурации. При обновлении подписки он удалит полученные конфигурации и балансировщики и заменит их новыми. Скрипт сделан так, чтобы не нарушать структуру конфигурации sing-box даже если там есть комментарии, так что можете не бояться что что-то сломается или сотрётся.  

Чтобы изменить настройки балансировщиков, нужно изменить переменные в скрипте `/bin/singbox-subs-parser.py`. Скрипт поддерживает фильтрацию по протоколам и RegEx фильтрацию по тегам конфигураций, это настраивается в `/etc/init.d/S99sing-box` соответствующими параметрами.  

По умолчанию он выбирает все протоколы и отсекает типичные названия LTE и Авто конфигураций в подписках.  

> [!CAUTION]  
> ВАЖНО!  
> Скрипт обновления singkeen затрагивает скрипты `/etc/init,d/S99sing-box`, `/bin/singbox-subs-parser.py` и заменит их при обнаружении отличий от версии в репозитории. Если вы изменяли какие то параметры на свои, то отключите авто обновление!   

# Обновление  

Скрипт поддерживает проверку обновлений с репозитория, для этого достаточно выполнить `singkeen.sh update`. Так же при интерактивной установке скрипт предложит включить авто обновление. Авто обновление затрагивает только скрипты, конфигурации остаются нетронутыми. Скрипт сверяет файлы по хешу и заменяет если обнаружит различие.   

Скрипты затрагиваемые обновлением:  

- `/etc/init.d/S99sing-box` 
- `/etc/ndm/netfilter.d/050-singbox.sh` 
- `/bin/singbox-subs-parser.py` 
- `/bin/singkeen.sh`
